1. Project Overview & Objective

Qurilishi kerak bo‘lgan mahsulot — AI Rooftop Solar Auditor & Engineering Engine: foydalanuvchi aerofoto yuklaydi yoki preset tanlaydi; tizim tom yuzalarini va to‘siqlarni (mo‘ri, lyuk, HVAC) ajratadi; standart PV panellarini algoritmik joylashtiradi; kWp / kWh / ROI hisoblaydi; photoreal “after” render va PDF muhandislik hisobotini beradi.

Hakaton strategiyasi (muhim) Demo asosida haqiqiy Meta Model API bo‘lishi shart (SAM 3.1 + kamida bitta Muse model). Mock/Adapter faqat offline fallback va CI uchun. Default konfiguratsiya: API key bo‘lsa live, bo‘lmasa mock — UI va business logic o‘zgarmaydi.

1.1 Success definition (MVP)

  • 3 ta preset + custom upload ishlaydi.
  • Canvasda: tom (yashil), to‘siq (qizil), panel grid (ko‘k) ko‘rinadi.
  • Analytics: capacity, annual gen, cost, savings, ROI hisoblanadi.
  • PDF yuklab olinadi; Muse Image (yoki mock) render URL qaytadi.
  • USE_MOCK / API key orqali live/mock almashtirish bitta config bilan.

1.2 Non-goals (MVP dan tashqari)

  • GIS georeferensiya / haqiqiy GPS orthophoto pipeline.
  • To‘liq 3D BIM / CAD export.
  • Multi-user auth, billing, production cloud deploy.
  • Real-time shading simulation (kelajak feature sifatida qayd etiladi).

4. End-to-End Workflow & Pipeline

1

Upload & Detect

JPG/PNG upload yoki 3 preset. Validatsiya, project_id, dimensions.

2

AI Segmentation (SAM 3.1)

Zero-shot: roof planes + obstacles → polygon vektorlar.

3

Optimal Grid Layout (Shapely)

Usable area = roof ∖ obstacles(+buffer). Panel grid + setback.

4

Analytics + Muse render + Agent report + PDF

KPI hisoblash, photoreal “after”, qisqa engineering narrative, PDF.

4.1 Step 1 — Image ingestion

  • Preset 1: residential_gable.jpg — oddiy ikki tomonlama tom.
  • Preset 2: complex_hip.jpg — ko‘p qirrali hip roof.
  • Preset 3: commercial_flat_hvac.jpg — tekis tom + HVAC to‘siqlar.
  • Max file size: 15 MB. Format: JPEG/PNG. MIME tekshiruvi majburiy.

4.2 Step 2 — Segmentation output

Roof polygons #10B981 @ 35% fill
Obstacles #EF4444 @ 40% fill
Panels #3B82F6 stroke 2px
  • roof_polygons: List[List[Tuple[x,y]]] — image pixel coords.
  • obstacles: xuddi shu format.
  • Kamida 1 ta roof polygon; obstacles bo‘sh bo‘lishi mumkin.

4.3 Step 3 — Layout engine rules

  • Panel physical size: 1.7 m × 1.0 m.
  • Pixel scale MVP: har bir preset uchun fixed meters_per_pixel (config yoki preset metadata). Custom upload uchun default 0.05 m/px (sozlanadigan).
  • Setback / obstacle buffer: 0.3 m.
  • Grid: axis-aligned per roof polygon (rotation = roof dominant edge angle, MVP da 0° yoki polygon long-edge).
  • Panel obstacle yoki tashqi chegaraga chiksa — discard.

Usable area:

Usable = RoofPolygon.difference(unary_union(Obstacles).buffer(setback_px))

4.4 Step 4 — Engineering formulas

MetricFormulaDefault const
Capacity (kWp) N_panels × panel_kw 0.400 kW / panel
Annual generation (kWh) Capacity × peak_sun_hours 1,450 h
Installed cost (USD) Capacity × cost_per_kw $800 / kW
Annual savings (USD) AnnualGen × tariff $0.12 / kWh
Payback / ROI (years) Cost / AnnualSavings ~4.6 y (example)

Barcha konstantalar config.py da markazlashtirilgan bo‘lsin.

5. Meta AI Integration (Adapter Pattern)

5.1 Config

# .env / config.py
USE_MOCK=false                 # true → force mock
META_API_KEY=...               # bo‘sh bo‘lsa auto-mock
META_API_BASE_URL=https://...  # Meta Model API base
SAM_MODEL=sam-3.1
MUSE_IMAGE_MODEL=muse-image
MUSE_TEXT_MODEL=muse-spark     # yoki muse-wonder

5.2 Segmentation adapter

Interface:

class SegmentationService(Protocol):
    def segment(self, image_path: str, width: int, height: int) -> SegmentationResult:
        ...

# SegmentationResult:
#   roof_polygons: list[list[tuple[float, float]]]
#   obstacles: list[list[tuple[float, float]]]
#   provider: "meta-sam-3.1" | "mock"
#   latency_ms: int

Live (SAM 3.1)

  • Zero-shot promptlar (yoki API talab qiladigan format):
    • Roof: “pitched or flat roof surfaces suitable for solar panels”
    • Obstacles: “chimneys, skylights, HVAC units, vents on the roof”
  • Mask → contour (OpenCV ixtiyoriy; MVP da API polygon qaytarsa to‘g‘ridan-to‘g‘ri; aks holda mask raster + simple contour).
  • Timeout: 60s. Xato → controlled error + UI da aniq xabar; ixtiyoriy mock fallback faqat ALLOW_MOCK_FALLBACK=true bo‘lsa.

Mock

  • Image aspect ratio asosida ishonchli polygonlar (preset_id bo‘yicha farqli shablonlar).
  • Har bir preset uchun kamida 1–2 roof plane va 1–4 obstacle.
  • Provider field: "mock" — UI statusda ko‘rinsin.

5.3 Render adapter (Muse Image)

class RenderService(Protocol):
    def render_after(
        self,
        image_path: str,
        panels: list[Panel],
        roof_polygons: list,
    ) -> str:  # relative URL under /static/renders/
        ...
  • Live: aerial + panel layout tavsifi bilan photoreal “rooftop with installed solar panels” generatsiya.
  • Mock: Pillow bilan panel to‘rtburchaklarini original rasm ustiga chizib JPEG saqlash (demo hech qachon bo‘sh qolmasin).

5.4 Agent report (Muse Spark / Wonder)

  • Input: panel count, capacity, obstacles count, roof area estimate, ROI.
  • Output: 120–180 so‘zlik engineering summary (risklar, tavsiya, next steps).
  • Mock: template string + interpolated numbers.
  • Response schema maydoni: analytics.agent_summary.
Hakaton demo talabi Submission video/livestreamda status barida Meta SAM 3.1: Live va Muse Image: Live ko‘rinishi afzal. Faqat mock bilan yuborish — yutuq ehtimolini pasaytiradi.

6. Layout Engine & Analytics Detail

6.1 Panel placement algorithm (MVP)

  1. Har bir roof polygon uchun Shapely Polygon yaratish.
  2. Obstacles union + buffer.
  3. usable = roof.difference(obstacles_buffered).
  4. Usable bounding box bo‘ylab grid step = panel_w_px + gap_px (gap default 2 px).
  5. Har bir candidate box(x, y, x+w, y+h) uchun: usable.contains(panel) yoki panel.within(usable) — true bo‘lsa accept.
  6. Panel record: {id, x, y, width, height, rotation} — x,y = top-left pixel.

6.2 Analytics module

  • Barcha floatlar 1–2 kasr aniqligida round.
  • roi_years: savings ≤ 0 bo‘lsa null + UI da “N/A”.
  • Qo‘shimcha maydonlar (ixtiyoriy MVP+): usable_area_m2, panel_density.
